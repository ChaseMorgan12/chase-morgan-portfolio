<i>Dimensional Delivery</i> is a mobile puzzle simulator game where you work at a packaging facility that uses portals for delivery. 

My work on this project included creating all mechanics like hte portals, physics, gel, and all other heavy hitting features for this game. It was made using Unity 2022 URP in C# with many features made with Android Studio with Java.
