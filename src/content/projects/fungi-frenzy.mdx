<i>Fungi Frenzy</i> is a physics driven co-op action game built with Unity by <i>Ashen Sky Studio LLC</i> with rogue-like elements where players explore corrupted fantasy environments, complete timed trials, throw almost anything-including each other and survive chaotic encounters that may end in betrayal.

My work on this project includes overseeing two other programmers, main networking code, game navigation, and player systems. A lot of work on this project utilizes C# for system with game navigation using Unity UI Toolkit leveraging CSS and XML like syntax
