Sprint five is long and gone and stood to be a sprint of a lot of art addition and general quality of life improvements. We're at the stage where programming isn't the most important thing needed, as new features aren't being added and only bugs need to be squashed. Nothing major was added during the sprint; however, some big changes to the game style was changed. One of those being the portals! Portals now have two colors to further help the player know which portal is which. They are also square now to align more with the box shape.

The most amount of work this sprint was spent implementing all sprites that were made for the game. It was really fun seeing the transformation the game had after adding all the amazing sprites made by our team. The job didn't just entail slapping the sprite on and calling it a day, most of the UI had to be redesigned and moved around. Some of it had to be programmed to alongside the new buttons. One big help was the Unity Sprite Editor as it allows the quick definition of a sprite's outline so that one background sprite can be used for any size or shape decreasing the size of the game substantially.

Another thing that is substantial enough to warrant an entire paragraph is the hint system and par system. The hint system allows the player to get help when they are stuck and does so at the level designer's discretion. If they want to be cryptic and give a subtle hint they can, or they can just tell the player the solution. It also allows subsequential hints, which means that the level designer can have the first few hints give the player a subtle hint and then later ones just tell the player the solution. This allows the system to be very modular and if the level doesn't have a hint the system will just tell the player to experiment with different solutions. The par system will tell the player in real time if they are on track to get a bronze, silver, or gold star. It just basically shows the player via UI how many portals are placed and what the health of the crate is compared to the par set by the level designer.

Other work this sprint includes a lot of bug fixes, QoL, and other UI work. I will just quickly rapid fire everything that was done and talk about the more significant items. Other work included gel optimization, new SaveManager for easier saving, saved settings, portal toggle button, ALR sheet for sprites, UI alignment to screen safe areas, version number, portal placement whilst rotating, feedback form button in-game, different gel colors, bigger portals, and maximum dropper drops.

Notable additions from that list include portal toggling, UI alignment, feedback button, and the new SaveManager class. Portal toggling was a feature wanted from many playtesters and allows the player to toggle which portal they want to place instead of having the game choose for them. They can opt to not use this feature in the settings. UI alignment is a lot more critical for mobile games as certain phones have physical elements (e.g. selfie cameras) blocking parts of the screen. I made a class that can be added to any UI element to make sure the element is aligned to the safe area (the area that 100 percent visible to the player) of any device. You can choose which side you want it to be aligned to. The feedback button is great for gathering feedback from our players as it links to the current feedback form that is listed in the Google Play Console. This allows us to easily gather feedback without having to send out the link or have them scan a QR code like we have been doing. Lastly a SaveManager class has been added to alleviate saving in game; the system can save to binary or JSON and is generic so any serializable class can be used. This allowed a more streamlined approach to data saving in classes so that less junk is inside each class.

This sprint I moved 17 cards which is a new personal record, and I am ready for the final push to get this game fully playable for this second to last sprint. The next sprint is looking to be mostly QoL; however, a new zoom feature for placing portals is underway and it's going to hopefully solve all the problems regarding portal placing. I am hopeful and excited for this next sprint and with a little luck, this sprint can go just as smoothly as sprint five!
